The long pass, standing behind the card

Back to the long pass (42 × 16em, 2.625 : 1). It is always turned −90° (you read it from the right side of the screen) and always the same size: the plane card's scale, 450 px long on a 375 px phone. Behind the card it stands upright and centred with only its stub end showing above the card; that end now carries the airline, route, flight and date written along the edge, so the strip reads on its own. Swipe and it comes forward, tilting a few degrees, with no turn and no scaling. The stub's code is a real QR code (made by qr.mjs).
